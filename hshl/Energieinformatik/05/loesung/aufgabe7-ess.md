# Musterlösung zu Aufgabe 7: ESS und Fahrpläne

Schauen Sie hier erst hinein, wenn Sie die Aufgabe **selbst** gelöst haben.

| Frage | Antwort |
|---|---|
| Wie heißt das Format? | **ESS**, das *ETSO Scheduling System*, entwickelt von ETSO, der Vorgängerorganisation von ENTSO-E |
| In welcher Sprache ist das Informationsmodell beschrieben? | **UML**. Das Informationsmodell ist als UML-Klassendiagramm beschrieben, das XML-Schema wird daraus erzeugt. |
| In welchem Datenformat werden die Fahrpläne serialisiert? | **XML** |

Ergänzend: Marktpartner und Regelzonen werden über **EIC-Codes** identifiziert, z. B. `11XBKV-MUSTER-1` im Beispiel der Vorlesung. ESS wird zunehmend durch CIM-basierte Profile wie das **ESMP** (IEC 62325) abgelöst.
